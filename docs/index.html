Dual-Arm UR3 / UR3e + Allegro Hand Drivers

The workspace that brings up a bimanual torso: two Universal Robots arms, two 16-DoF Allegro Hand V4 over PCAN, three RealSense cameras, a calibrated URDF with collision geometry, and bridge nodes so any program (a learned policy, a grasp planner, teleoperation) can drive the cell with joint-position topics.

What one launch file brings up

armsUR driver + ros2_controlBoth arms' hardware interfaces, forward-position / trajectory / velocity controllers, dashboard and safety stopper per arm.
handsAllegro V4 driverPID joint-position control over CAN, with a PWM ceiling that keeps the thumb motor from overheating.
camerasRealSense, patchedColour + depth per camera. Calibrated intrinsics load from YAML via camera_info_url, and extrinsics are published as static TFs to world.
bridgesTopic-level controlMerged joint states, arm streaming with damping, and hand streaming that releases when its input topic goes silent.

Robot description: visual and collision

The URDF is generated by xacro at launch: world, T-shaped stand and table, a UR3e and a UR3 with their factory kinematic calibrations, and an Allegro hand on each flange (prefixes la_ / ra_). The same model is exported to Isaac Lab for sim-to-real work.

Try it

git clone https://github.com/ismael-esp/dual-arm-allegro-ros2.git && cd dual-arm-allegro-ros2
bash scripts/install_pcan_host.sh      # host: PEAK pcan kernel module
bash docker/build.sh                   # ROS 2 Jazzy + ros2_control + UR + MoveIt + librealsense + PCAN libs
bash docker/run.sh                     # repo mounted at /home/dev/ros2_ws
bash scripts/setup_workspace.sh        # pinned upstream drivers + RealSense patch + colcon build
source install/setup.bash
ros2 launch my_dual_robot_cell_control start_system_drivers.launch.py      # real robot
ros2 launch my_dual_robot_cell_control start_robots.launch.py \
    la_use_mock_hardware:=true ra_use_mock_hardware:=true                  # no hardware
